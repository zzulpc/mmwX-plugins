### 最终行为

1. **解析与输出**：同步凭据加号/百分号、Hysteria 端口跳跃、AnyTLS REALITY、隐式 TLS 的 SNI、WireGuard 的地址/保活及 sing-box endpoint/peer 层级，以及各客户端协议/字段更新。本地补齐 Hysteria 1 标准认证与混淆字段、IPv6/特殊字符往返、VMess H2 Host 双入口，并验证跳跃范围边界。
2. **模板与路由**：支持嵌套 YAML 合并和别名，显式 DIRECT/REJECT 不被一般 filter 误删。缺失集合、无法等价解释的表达式、被删除策略仍被规则/链引用时明确报错。拒绝上游中自动改成 DIRECT、绕过前置代理或用全部节点补组的行为；Loon 还检查直接链循环和落地别名冲突。Surge 两种前置字段统一保留，Shadowrocket 短规则与字符串列表不触发默认路由。
3. **测速生命周期**：内核定位锁和版本检查遵守取消，整段定位共用 15 秒上限；执行预算从 58 秒增至 73 秒，另有 60 秒排队预算。WebSocket 写失败关闭连接并取消任务，触发读循环退出。共享下载额度在暂被预留时等待结算，失败读取退回额度后继续工作。移除无效的大块拷贝缓冲，保留原有线程和 256MB 保守缓冲预算。
4. **技能与工具清单**：保留原有授权、有限等待和任务关联规则，补转发、证书、日志/任务、套餐实例与路由更新流程。所有技能先核对完整分页 `tools/list` 和实时 `inputSchema`；27 个新增工具仅声明为可选能力。清单脚本收集全部分页，拒绝重复/不完整清单，可比较去掉说明/默认值/示例的输入约束快照；CI 增加离线 Python 检查。
